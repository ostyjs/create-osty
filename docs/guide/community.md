# Community and Support

## Get help

Join the [Osty community on Telegram](https://t.me/ostyjs) to ask questions and
follow project updates. Search existing
[GitHub issues](https://github.com/ostyjs/create-osty/issues) before opening a new
report.

A useful bug report includes:

- The command or application action that failed.
- What you expected and what happened.
- The error output and steps to reproduce the problem.
- Your operating system, Node.js version, and package-manager version.

Remove private keys and other credentials from reports.

## Contribute

Read [CONTRIBUTING.md](https://github.com/ostyjs/create-osty/blob/main/CONTRIBUTING.md).
Fork the repository, create a focused branch, and open a pull request that
describes the change and its validation. Documentation contributions are welcome.

Use the [development guide](./development) to build the CLI or preview this site.

## Support the project

Osty's README describes its OpenSats support and the maintainer's donation
options. Use the [current support information](https://github.com/ostyjs/create-osty#support)
for those details.
