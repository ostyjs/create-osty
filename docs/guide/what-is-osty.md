# What is Osty

Osty helps you build web applications for the Nostr protocol. Its `create-osty`
CLI copies a template into a project that you can edit and own.

The current template is **Nostribe**, a React and TypeScript Nostr client. It
combines Vite, Nostr Development Kit (NDK), `nostr-hooks`, React Router, Zustand,
Tailwind CSS, and reusable UI components.

## What you get

- A working application structure with routes and a shared layout.
- UI components that you can edit in your own source tree.
- Feature widgets for login, notes, profiles, messages, notifications, and zaps.
- Nostr hooks for the active user, subscriptions, and events.
- Development, build, preview, formatting, and lint commands.

Osty gives you source code to adapt. It does not host your application or operate
your relays. Relay access, signing, and deployment remain part of your project.
